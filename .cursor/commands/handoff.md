# handoff

Write a handoff note to `HANDOFF.md` at the repository root so another agent can continue this work. Include only what is not already in `AGENTS.md`, `architecture.md`, or `blueprints/`.

Cover:

- Decisions made this session, with reasons and rejected alternatives.
- Current state: what is done, in progress, and verified.
- Open tasks, each with its next step.
- Key file paths.
- Lessons: what you got wrong first and fixed through trial and error. Write each as a general agent rule that is not specific to this project.
